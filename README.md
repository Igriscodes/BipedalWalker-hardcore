# BipedalWalker-hardcore
Reinforcement learning agent using JAX to solve the BipedalWalkerHardcore-v3 environment

* **Training:** Trains a JAX-based agent on `BipedalWalkerHardcore-v3`, a challenging 2D physics task where a bipedal robot must learn to walk and navigate obstacles (stumps, stairs, and pitfalls). The training runs for **3.5 million steps** over 60 minutes, reaching an evaluation return of **315.1**.

* **Evaluation:** Evaluates the trained policy on a test episode—achieving a final score of **319.87**.
